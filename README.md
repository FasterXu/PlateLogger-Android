# 车牌记录（Android）

当前版本：`1.9.2 (13)`

面向小米及其他 Android 手机的本地车牌识别记录应用。摄像头画面只在设备上处理；应用没有声明网络权限，识别结果、位置和截图保存在应用私有目录中。

## 已实现功能

- CameraX 后置摄像头实时取景与逐帧分析
- 单帧达到置信度阈值后立即识别和记录，提高识别效率
- 底部独立“设置”页面可在 70%–98% 间调整置信度阈值，设置会持久保存
- 扫描页默认保持屏幕常亮；可关闭常亮，或启用 30 秒无操作后自动进入的低亮度识别模式，轻触即可恢复
- 主界面移除顶部标题栏，底部提供“识别、记录、设置”三个独立页面
- 取景提示框中心位于画面上方 1/4 处，支持点按车牌对焦和双指缩放；转动手机后保持当前缩放倍率
- 支持横屏识别；横竖屏均使用全区域取景和覆盖式状态面板，并采用兼容渲染模式减轻旋转时的画面跳变
- 识别并保存车牌类型，包括新能源、大型车辆/货车、使领馆、警用、教练及港澳等特殊车牌；识别页不再额外显示类型文字行
- 车牌号码牌按识别类型显示对应底色：蓝牌为蓝底、黄牌及大型货车为黄底、新能源为绿底、警用等为白底、使领馆及黑色港澳牌为黑底
- APK 同时启用 v1、v2、v3 签名方案，兼容部分旧版 MIUI 和第三方安装器
- 调用 GitHub 开源项目 [HyperInspire/hyperlpr3-android-sdk](https://github.com/HyperInspire/hyperlpr3-android-sdk) 进行中国车牌识别
- 保存车牌号、出现时间、经纬度、定位来源、置信度和车牌裁切图
- 相同车牌至少间隔 1 分钟才会再次记录，避免静止画面产生大量重复记录
- 本地 SQLite 历史记录按车牌号分组索引；点击车牌可查看该车牌的全部截图与出现时间
- 车牌详情支持录入最多 80 字的文本备注；记录索引会显示备注，再次识别到该车牌时识别页会用醒目的高对比提示块显示备注
- 车牌缩略图可点击进入黑底完整图片查看页
- 保存截图以检测框中心为基准，宽度和高度均扩大到原车牌检测框的 2 倍
- 记录索引支持左滑后确认删除单个车牌及其截图，并支持二次确认后删除全部记录
- 导出 ZIP：UTF-8 BOM 编码并包含备注的 `车牌记录.csv`，以及 `images/` 下的全部车牌截图
- 支持 `arm64-v8a`、`armeabi-v7a`，最低 Android 7.0（API 24）

## 构建

推荐使用 Android Studio，配置 JDK 17 和 Android SDK 35，然后打开本目录并运行 `app`。首次构建需联网从 Google Maven、Maven Central 和 JitPack 下载依赖。

命令行构建（工程安装 Gradle Wrapper 后）：

```text
./gradlew assembleDebug
```

Gradle 原始输出位置：`app/build/outputs/apk/debug/app-debug.apk`。本版本已验证、可直接安装的成品位于 `dist/PlateLogger-v1.9.2-MIUI-compatible.apk`。

> 当前源码目录不包含第三方算法二进制；Gradle 会固定拉取 HyperLPR3 `1.0.3`。识别模型与 JNI 均来自该成熟项目，本项目没有自行编写车牌检测/OCR 算法。

## 使用

1. 首次启动时允许相机权限；位置权限可选，拒绝后仍能识别，但记录不含经纬度。
2. 将车牌放在画面上方 1/4 处的取景框内，单帧达到阈值后会立即记录。
3. 在取景画面点按车牌可调焦，双指捏合可调整变焦倍数；手机横放时会自动切换横屏布局。
4. 打开底部“设置”页，通过“置信度阈值”按钮在 70%–98% 间调整；误识别较多时可提高，漏识别较多时可降低，默认 88%。
5. 在“设置”页点击“屏幕”按钮控制扫描时常亮和低亮度模式；默认保持常亮，并在 30 秒无操作后降低亮度，轻触屏幕恢复。
6. 打开“记录”页并点击车牌，在详情页输入备注后点击“保存备注”；以后识别到该车牌时会在识别页显示备注。
7. 点击“导出 ZIP”，选择小米文件管理器或其他文档提供器中的保存位置，CSV 中会包含车牌备注。

## 小米手机提示

- 如果取景黑屏，请在“设置 → 应用设置 → 应用管理 → 车牌记录 → 权限管理”中开启相机。
- 若位置长期为空，请同时开启系统定位，并授予“仅在使用中允许”的精确或大致位置权限。
- 应用只在前台识别，不申请后台定位，也不需要关闭 MIUI/HyperOS 的电池优化。

## 数据与隐私

- 所有识别和保存均在本机完成，未声明 `INTERNET` 权限。
- 截图位于应用私有目录，卸载应用会一并删除；需要长期保留时请先导出 ZIP。
- 车牌与位置属于敏感个人信息，请仅在获得合法授权的场景使用，并妥善保存导出文件。
